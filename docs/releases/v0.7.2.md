# Windows 通知 v0.7.2

完整版本新增「点击通知打开 DSH」开关，减少点击通知后返回已有页面的等待，并调整设置页输入框宽度。

## 本版更新

- **打开 DSH 可单独关闭。** 在「设置 → Windows 通知」中关闭「点击通知打开 DSH」并保存，新通知隐藏打开按钮，点击正文只收起；旧通知的打开按钮也只收起通知，不打开或切换浏览器。默认开启，旧设置继续保持原有行为，与聚焦通知开关独立。
- **返回已有页面更快。** 优先直接激活当前显示 DSH 的浏览器窗口，需要查找其他标签或恢复焦点时才加载无障碍接口；减少点击程序的启动依赖，普通点击不再额外搜索中转标签页。本机 Edge 测试已确认快速切回。
- **焦点处理更准确。** 直接激活后检查实际前台窗口，Windows 拒绝激活时回退到选择已有 DSH 标签页。
- **设置输入框更协调。** 桌面布局使用较窄的文字输入框，小窗口继续自动换行；通知预览会随打开开关显示或隐藏对应按钮。

任务栏橙色提醒高亮尚未确认解决，部分 Windows 系统仍可能保留。多个 DSH 标签页按标题选择，暂不定位通知对应的具体会话。v0.7.1 的中文及特殊字符图片路径修复继续保留。
