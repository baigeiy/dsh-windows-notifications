# Windows 通知 v0.7.1

修复安装目录包含中文时，通知正文旁的图片可能无法显示的问题。

## 本版修复

- 调整本机通知图片地址的处理方式，让 Windows 能够读取中文路径下的图片。
- 图片路径中的空格、`#`、`%` 和 `&` 等字符也经过处理；英文路径继续支持。
- 在本机验证了中文及特殊字符路径的图片读取，并通过测试通知确认「大肥鱼」图片可以显示。

发行包包含 Windows x64 运行环境，无需安装 Python、uv、Git 或编译器。首次使用需在插件目录以管理员身份运行一次 `setup.ps1`，然后重新启用插件或重启 DSH Web；具体步骤见[项目安装说明](https://github.com/baigeiy/dsh-windows-notifications#安装)。

更新或移动插件目录后，请在新目录重新初始化。包管理器更新可能更换安装目录；更新前备份 `settings.json` 和自定义图片 `custom-*.png`。
