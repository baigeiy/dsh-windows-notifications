# Windows 通知 v0.7.0

提问、操作确认和对话完成时，收到一条可以自定义的 Windows 原生通知。

## 选择下载方式

| 下载 | 适合谁 | 安装方式 |
| --- | --- | --- |
| [Windows x64 ZIP](https://github.com/baigeiy/dsh-windows-notifications/releases/download/v0.7.0/dsh-windows-notifications-0.7.0-win-x64.zip) | 希望把插件和设置保存在固定目录 | 解压到长期保留的目录，以本地链接安装，推荐 |
| [预构建 tgz](https://github.com/baigeiy/dsh-windows-notifications/releases/download/v0.7.0/dsh-windows-notifications-0.7.0.tgz) | 使用 dsh 原生包安装命令 | 在 web profile 中安装压缩包 |

两种包都包含 Windows x64 所需的运行环境和原生程序，不需要用户安装 Python、uv、Git 或编译器。适用于 Windows 10/11 x64 的 dsh Web；点击返回已有页面的行为已在 Edge 实测。

## 首次使用

下载后，仍需在插件所在目录以管理员身份运行一次 `powershell -ExecutionPolicy Bypass -File .\setup.ps1`，再重新启用插件或重启 dsh Web。插件安装完成但尚未初始化时会报错。完整步骤和查找安装目录的方法见[项目首页](https://github.com/baigeiy/dsh-windows-notifications#安装)。

更新或移动插件后，请在新目录重新初始化。包管理器更新可能更换目录；更新前备份 `settings.json` 和 `custom-*.png`。

## 本版内容

- 预构建的 Windows x64 运行环境随发行包提供。
- 提问、操作确认和完成通知支持自定义标题与图标；聚焦时通知可单独设置。
- 「确认收到」收起通知；「打开 dsh」尝试切回已有标签页。
- 插件可以在 dsh 的已安装插件列表中启用或停用。

## 已验证

- 使用 DSH 原生 `plugin add` 将 `.tgz` 安装到独立 profile，无需编译或构建授权。
- 便携 Python 加载全部原生依赖；激活、标签页复用和聚焦逻辑共 13 项检查通过。
- 重复初始化、压缩包校验失败时保留现有运行环境、长路径拒绝提示通过检查。
- 本机 Windows 协议检测为 AVAILABLE。新版发行包尚未在另一台干净的 Windows 电脑上验证。

每个发行包约 27 MiB。下载 [SHA256SUMS.txt](https://github.com/baigeiy/dsh-windows-notifications/releases/download/v0.7.0/SHA256SUMS.txt) 可以核对完整性。原生启动器暂未作代码签名；Windows 的安全提示仍适用。

更多使用限制、本机数据和维护信息见[开发与维护](https://github.com/baigeiy/dsh-windows-notifications/blob/main/docs/development.md)。
